# Java Desktop Calculator

A lightweight, modern, and fully interactive desktop calculator built from scratch using Java Swing. This project was developed as a hands-on practice for GUI architecture, event-driven programming, and modern Java features.

## Features
- **Modern Aesthetics:** Clean, dark-mode color scheme with distinct control and function layouts.
- **Robust Math Logic:** Handles standard operations seamlessly.
- **Smart Display:** Automatically truncates unnecessary decimal zeroes for pure integer results.
- **Error Handled:** Integrated checks for formatting and operational states.

## Built With
- **Language:** Java
- **UI Framework:** Java AWT & Swing (JFrame, JPanel, JButton, JLabel)
- **IDE Environment:** Visual Studio Code

## Future Goals (Scientific Edition)
This project is an evolving workspace. The current version covers basic arithmetic stable states. The next milestone is to upgrade this application into a Scientific Calculator, adding powers, logarithms, trigonometric logic, and parenthesis parsing.

## How to Run
1. Clone the repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```
2. Open the project folder in your favorite Java IDE (e.g., VS Code).
3. Run the App.java file to launch the application.
